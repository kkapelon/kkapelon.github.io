Professional work

Most of my daily development used to happen behind closed doors. I cannot show any code without approval. As the old adage goes "if a module takes x effort to develop, it needs 3x to make it reusable in your other projects and 9x effort to make it reusable for other people". Lately I am truly lucky to get paid for open-source work in the Cloud/K8s ecosystem.

  • I maintain the Argo Rollouts Gateway API Plugin and also contribute to Argo Rollouts core.
  • I wrote the support for pluggable outputs in the DaisyDiff Library
  • I wrote a small Java library that reads perl configuration files
  • I wrote a toy web server in Clojure as a demonstration for this blog post.

Pet projects

EasyDentist was a commercial application aimed at dentists. It holds patient history and operations. It is implemented in Java and Swing. At the moment it only supports the Greek Language. The project has been discontinued.

Project Elevate was my attempt to create a new workspace manager for Linux, using C and Cairo graphics. The project is now abandoned because of lack of time. Its ideas still hold and I may resurrect in the future.
